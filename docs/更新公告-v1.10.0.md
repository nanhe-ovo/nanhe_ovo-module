# 南何ovo v1.10.0 更新公告（短版 / 酷安可用）

这次重点修“游戏帧率忽高忽低”和三角洲闪退。

- 新增游戏前台动态调度：游戏进前台自动拉起对应调度，退出回均衡，灭屏切省电；
- 线程主线程/渲染线程不再全钉单颗大核，改成双大核，小核也参与 worker；
- 三角洲行动因 ACE 反作弊对线程亲和性敏感，已加入跳过名单，绑定时会提示原因；
- 全 111 份 SoC 配置的 999 功率墙改成有限分档，DDR 上限不再长期 100%，新增平滑温控；
- 骁龙 GPU 不再把最低档钉死，恢复内核热控。

刷入后建议重启一次；三角洲若仍闪退，请把 `/data/adb/nanhe_ovo/log.txt` 和 ACE 相关 logcat 发回。
