# 南何ovo v1.11.0 更新公告（短版 / 酷安可用）

这一版重点：去掉内嵌 uperf，CPU 调度改为自研表驱动；顺手修掉升级后三角洲仍走旧性能规则的问题。

- 删除 `bin/uperf`，不再启动 uperf 进程；原 JSON 功耗配置全部保留，构建时生成每簇频率上限表，运行期由 `cpu_policy.sh` 直接写 cpufreq；
- 游戏前台检测改为轻量 top-app 扫描，不再每 2 秒跑两次 dumpsys；游戏进前台切 `fast`，退出回 `balance`，灭屏省电；
- 覆盖升级会迁移旧版 `* performance` 分应用规则为新模板（游戏 `fast`、默认 `balance`），自定义包名保留；
- 温控模式切换时重置旧基线，避免 `fast` 被上一档的旧上限夹住；
- WebUI 底栏改为实色 Miuix 悬浮胶囊，移除液态玻璃、背景模糊、折射和镜片滑动。

刷入后重启一次。三角洲若仍有规律卡顿，请把 `/data/adb/nanhe_ovo/game_watch.log`、`thermal_guard.log` 和对应时间的 logcat 发回；约 92 秒一次的停顿还需要真机日志继续定位，不能只靠调频解释。
