# 南何ovo v1.12.0 更新公告（短版 / 酷安可用）

这一版按性能优先修掉《三角洲行动》长跑里的“过一会自动降频”。

- 温控起始温度从 74℃ 延后到 84℃，最高档从 88℃ 延后到 95℃；fast/performance 档位上限改为 90/80/70/55%，crazy 单独用 95/88/78/60%。
- 温控只压当前模式基线，不再把已经限制住的上限反向抬高；模式切换/启动不再恢复旧基线。
- 三角洲行动与 CE 默认 `crazy`；旧版 DFM `fast` 规则升级时自动迁移。
- CPU7 标准节点写入失败时自动走 MTK PPM / `cpufreq_limits` 兜底，并加并发锁与写前 chmod。
- 温控只看 CPU/SoC 热区；GPU 热区不再直接触发 CPU 降档。
- 版本：`v1.12.0` / `202611259`。

性能优先会换来更高温度；硬件温控仍保留。刷入后建议在游戏里抓一份 `thermal_guard.log` 和 `cpu_policy.log`，确认 84℃ 以上档位与 CPU7 写入。
