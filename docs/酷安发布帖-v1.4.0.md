## 正文

南何ovo（页面内名「性能调度」），基于开源 Uperf-Game-Turbo 的 Android 调度模块，自带本地 WebUI，不联网、不上传。arm64 可用，KSU / APatch / Magisk 通用，刷入重启生效。

**功能**
- 五种全局模式：省电 / 均衡 / 性能 / 极速 / 超频；支持分应用绑定策略
- CPU / GPU 频率只从设备真实频率表里选，表外拒绝，写入回读校验、失败回滚
- 刷新率 30–240Hz 十档，支持取消静止降频，修复开机锁 60Hz
- 机型信息、系统调优开关、本机运行日志（最多 200 行）

**v1.4.0 更新**
- 新增「超频」档：75 份配置全部补齐，推高可写集群上限到表内最高档；离开自动恢复基线，只读节点记日志跳过
- 新增 7 份 2026 新平台推测配置（天玑 9600 Pro / 9600M / 9500s / 8500、骁龙 8 Elite Gen 6 / Extreme Gen 6、Exynos 2700），板级代号未公开前不自动匹配
- 三份原理 / 策略 / 降频分析文档随包
- 后端 228 条断言全通过，前端五屏渲染通过，打包 114 文件 / 75 配置

**安装**：管理器刷入 `nanhe_ovo-v1.4.0-20261117.zip` → 重启 → 模块页打开 WebUI。

**注意**
- 超频不突破出厂上限、不动电压；能否推满由内核与温控决定
- 2026 配置为推算值，需真机校准；频率区间不持久化，会被调度覆盖
- 日志只存本机；玻璃效果为 CSS 近似

**出处**：引擎来自 [yinwanxi/Uperf-Game-Turbo](https://github.com/yinwanxi/Uperf-Game-Turbo)（Apache-2.0）；模块外壳与 WebUI 本地实现，Apache-2.0 发布。
