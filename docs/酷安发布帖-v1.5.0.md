## 正文

南何ovo（页面内名「性能调度」），基于开源 Uperf-Game-Turbo 的 Android 调度模块，自带本地 WebUI，不联网、不上传。arm64 可用，KSU / APatch / Magisk 通用，刷入重启生效。

**v1.5.0 更新**
- 补全 23 份 2020 年以来存量平台推测配置：天玑 6100+/7050/1100/9300/7050/8400、麒麟 990/9000/9000S/9010/9020、Exynos 1080/1480/1580/2400、Tensor G4、骁龙 8s Gen3 / 8 Elite / 7+ Gen2 / 6 Gen1、展锐 T310 / SC9832E
- 推测配置按旗舰 / 中端 / 入门三档落静态调度，功耗上限与余量对齐既有旗舰、入门件；五模式场景覆盖沿用模板
- 平台映射补入 8 Elite、7+ Gen2、8s Gen3、6 Gen1、Exynos 1480/1580/2400、麒麟 9000S/9010/9020、天玑 8400
- 修复上游遗留 sdm210 配置无法解析的问题，并补齐其超频档；全量配置纳入 JSON 可解析校验
- 后端 242 条断言通过，前端五屏渲染通过，打包 137 文件 / 98 配置

**安装**：管理器刷入 `nanhe_ovo-v1.5.0-20261118.zip` → 重启 → 模块页打开 WebUI。

**注意**
- 推测配置按公开规格推算，需真机校准；未列入手册的中低端、平板、车规芯片仍回退通用模板
- 超频不突破出厂上限、不动电压；能否推满由内核与温控决定
- 频率区间不持久化；日志只存本机；玻璃效果为 CSS 近似

**出处**：引擎来自 [yinwanxi/Uperf-Game-Turbo](https://github.com/yinwanxi/Uperf-Game-Turbo)（Apache-2.0）；模块外壳与 WebUI 本地实现，Apache-2.0 发布。

仓库：<https://github.com/nanhe-ovo/nanhe_ovo-module>
