# 酷安发布帖 · 南何ovo v1.6.0

## 标题

南何ovo · 性能调度 v1.6.0｜天玑 GPU 稳频、骁龙低分组优化、刷新率总开关

## 正文

南何ovo 是基于 Uperf-Game-Turbo 的本地调度模块，支持 Magisk / KernelSU / APatch，自带 WebUI，不联网、不上传数据。

### v1.6.0 更新

1. **天玑 GPU 稳频**：恢复内核 fast DVFS，按模式在真实 OPP 表内抬 GPU 下限。性能档 75%、极速 85%、超频 95%，只抬下限、不改上限，省电 / 均衡恢复开机快照，缓解 GPU 频率大幅锯齿和来回跳频。
2. **骁龙 8 Elite 低分组优化**：开启低分组调度，把 `0-1` 设为轻载组，音频、网络、解码线程定向派活，由负载驱动升频，不再靠强抬 `min_freq`。
3. **SUSFS 状态检测移除**：状态页不再报告 SUSFS，不写告警；兼容探测代码保留，不影响已有 Root 环境。
4. **刷新率管理总开关**：新增开关。开启后强制固定刷新率上下限；关闭后模块完全不写系统刷新率，开机也不抢档，彻底交还系统。
5. **配置与测试**：保留已有可用配置，仅定向调整 8 Elite；补齐 GPU、刷新率开关、8 Elite 相关测试，后端与前端测试全部通过。

### 使用提示

- 仅支持 **arm64** 设备，刷入后重启生效。
- 刷新率管理默认关闭；需要锁帧时在频率页打开，再选档位。
- 天玑 GPU 与骁龙低分组效果因内核、厂商策略而异，建议按自己的帧率曲线微调。
- 超频档只把可写集群推到表内最高档，不升压、不突破出厂频率上限。
