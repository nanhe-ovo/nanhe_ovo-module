    熟悉的亲和感，独立的设计

    采用 Miuix 观感的浅灰底、纯白大圆角卡片、绿色状态卡与底部实色悬浮胶囊导航；不再使用液态玻璃、背景模糊或折射层。这是独立实现的 HTML / CSS / JavaScript 页面，并非原生 Miuix，与 Miuix、Xiaomi 无隶属或官方关系。

    底栏设计

    底栏是离底边 14px 的实色悬浮胶囊：纯白（深色为主题卡片色）、大圆角、极轻投影，当前页用浅蓝色胶囊高亮。没有 backdrop-filter、折射带、色散或镜片滑动，滚动时也不做玻璃形变；视觉层级完全交给 Miuix 的实色卡片与留白。

    配置与脚本来源

    CPU 功耗模型与部分启动脚本骨架来自 Uperf-Game-Turbo（作者 Matt Yang / 吟惋兮，Apache-2.0）；v1.11.0 起不再内置或启动 uperf 二进制，仅保留 JSON 配置与许可声明。模块内的 LICENSE 与 NOTICE 保留了原始声明。

    线程引擎来源

    线程调度引擎来自 AppOptR（作者 SutoLiu，GPL-3.0）：按本机拓扑实时解析 e-core / p-core / hp-core 语义核，进程创建与线程改名即时生效，内核无 BTF 时自动回退轮询模式。出处：gitee.com/sutoliu/AppOptR ↗，GPL-3.0 许可证文本随模块分发（appopt/LICENSE-GPL3.txt）。

    本项目

    源码发布在 github.com/nanhe-ovo/nanhe_ovo-module ↗；版本更新由管理器模块仓库统一推送。

    管理器与权限

    需要支持模块 WebUI 且提供 KernelSU 官方 callback 执行桥接的管理器（KernelSU / APatch 等），并授予 Root。Magisk 本体没有模块 WebUI，可用 KsuWebUIStandalone 一类工具打开同一页面。Root 不可用时只展示只读演示，绝不伪造写入成功。

    能力与安全边界

    支持不代表所有 GPU 都能调频，节点缺失、只读或厂商限制都会影响结果。本面板不关闭温控（系统调优关闭时也不做任何厂商进程处理）、不提供频率持久化；请保留合理频率范围，避免过热与不稳定。

    KernelSU 官方桥接定义 ↗

    外部链接需联网；面板本身与全部资源均可离线使用。
